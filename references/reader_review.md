# 读者层通读：给一个没参与改写的模型（第零节）

用法：把下面的提示词和稿件（或一节）一起交给一个**没参与改写**的模型（ChatGPT、Codex、另一个 Claude 会话都行）。
**不要附任何指标、语料数字或本 skill 的规则**，否则它会去核对数字，而不是当读者。
2026-10 那篇民法稿的七类问题，就是这样读出来的；本 skill 的全部检测器当时都是全绿。

---

你是法学期刊的审稿人，母语中文，熟悉民法学论文的写法。请通读下面这篇稿子（或这一节），只当读者，指出哪里读着不对。
重点看七件事，每发现一处，引原句，说明问题，给出改法：

1. 抽象概念堆叠：有没有说不清指什么的抽象名词（如"那层关系""同一功能"）？能直接说出对象的，就不该用。
2. 不自然的表达：有没有法学论文里不会这样说的词句？
3. 反复解释同一件事：同一个意思是否换着说法讲了几遍？
4. 过度防御：是否每走一步都先替假想的反对者发言，再花几句证明这一步没问题？反对意见有没有出处？
5. 一句承担过多任务：一句话里是否同时说规则、讲原理、类推新情形、提出边界问题？
6. 术语不稳定：同一概念是否换着几个词说？
7. 推论过满：条文明文、解释论结论和作者自己的主张，是否分得清？有没有从条文直接推出条文没说的结论？

最后告诉我：你认为最严重的三类是哪几类，以及这篇稿子的核心命题是什么。
如果你读不出核心命题，或者觉得它被淹没了，请直说。
